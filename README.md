# 🤖 بوت Telegram الذكي

بوت مساعد ذكي مبني على GPT-4o — يكتب كود، يصلح أخطاء، يبحث في الإنترنت، وينفّذ كود.

## المتغيرات المطلوبة في Railway

| المتغير | الوصف | مطلوب |
|---------|-------|--------|
| `BOT_TOKEN` | توكن البوت من @BotFather | ✅ |
| `OPENAI_API_KEY` | مفتاح OpenAI API | ✅ |
| `OWNER_ID` | ايدي مالك البوت | اختياري |
| `OPENAI_MODEL` | النموذج (افتراضي: gpt-4o) | اختياري |
| `MAX_HISTORY` | عدد الرسائل المحفوظة (افتراضي: 30) | اختياري |

## القدرات

- 💻 **كتابة ومراجعة الكود** بأي لغة برمجية
- 🔍 **بحث في الإنترنت** عبر DuckDuckGo
- ▶️ **تنفيذ الكود** عبر Piston API (Python, JS, Go, Rust, Java, C++, Bash)
- 📄 **تحليل الملفات** النصية والكود
- 🖼️ **تحليل الصور** عبر GPT-4 Vision
- 💬 **ذاكرة المحادثة** — يتذكر آخر 30 رسالة
