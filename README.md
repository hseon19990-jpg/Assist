# 🤖 بوت تعديل GitHub بالعربي

بوت تيليجرام ذكي — أرسل `/start` وتكلم بالعربي مباشرة لإدارة مستودعك.

---

## المتغيرات المطلوبة

| المتغير | الوصف |
|--------|-------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_OWNER_ID` | رقمك من @userinfobot |
| `GITHUB_PERSONAL_ACCESS_TOKEN` | توكن GitHub |
| `GITHUB_OWNER` | اسم مستخدم GitHub |
| `GITHUB_REPO` | اسم المستودع |
| `GITHUB_BRANCH` | اسم الفرع (افتراضي: `main`) |

### الذكاء الاصطناعي (أضف واحداً فقط)

| المتغير | المصدر |
|--------|--------|
| `GROQ_API_KEY` | https://console.groq.com — مجاني |
| `GEMINI_API_KEY` | https://aistudio.google.com/app/apikey — مجاني |

البوت يتعرف تلقائياً على أيهما موجود.

---

## الأوامر

| الأمر | الوظيفة |
|-------|---------|
| `/start` | رسالة الترحيب |
| `/help` | دليل الاستخدام |
| `/repo` | معلومات المستودع |
| `/clear` | مسح سياق المحادثة |
| `/admin [ID]` | إضافة مسؤول (المالك فقط) |
| `/removeadmin [ID]` | إزالة مسؤول (المالك فقط) |

---

## كيف يعمل

1. أرسل `/start`
2. اكتب أي تعليمات بالعربي أو الإنجليزي

**أمثلة:**
> أضف ملف requirements.txt فيه flask وrequests

> عدّل index.js وأضف console.log في البداية

> اقرأ ملف package.json

> احذف ملف old.js
