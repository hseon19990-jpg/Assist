# 🤖 بوت رفع الملفات إلى GitHub عبر تيليجرام

بوت تيليجرام يتيح لك رفع الملفات والتعديلات مباشرة إلى ريبو GitHub.

## المتغيرات المطلوبة على Railway

| المتغير | الوصف |
|--------|-------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_OWNER_ID` | رقمك الشخصي على تيليجرام (من @userinfobot) |
| `GITHUB_PERSONAL_ACCESS_TOKEN` | توكن GitHub (يحتاج صلاحية repo) |
| `GITHUB_OWNER` | اسم المستخدم على GitHub (مثال: `hseon19990-jpg`) |
| `GITHUB_REPO` | اسم الريبو (مثال: `Assist`) |
| `GITHUB_BRANCH` | اسم الفرع (افتراضي: `main`) |

## كيفية الاستخدام

### رفع ملف مباشر
أرسل أي ملف للبوت، سيسألك عن المسار في الريبو.

### رفع محتوى نصي
```
/push
path: src/bot.js
message: تحديث دالة البداية
---
محتوى الملف كاملاً هنا
```

## الأوامر
- `/start` — عرض التعليمات
- `/status` — عرض الإعدادات الحالية
- `/branch <اسم>` — تغيير الفرع مؤقتاً
- `/cancel` — إلغاء العملية الحالية

## النشر على Railway
1. ارفع هذا الكود على GitHub
2. أنشئ مشروع جديد على Railway من الريبو
3. أضف المتغيرات أعلاه في إعدادات Railway
4. سيعمل البوت تلقائياً كـ worker
