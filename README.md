# 🤖 Replit Agent — بوت تيليجرام

وكيل برمجة ذكي يعمل على مستودع GitHub مباشرةً عبر تيليجرام.  
يقرأ الكود، يكتب الميزات، يرفعها على GitHub، ويشغّل الكود — تماماً مثل Replit Agent.

---

## الميزات

| الميزة | الوصف |
|--------|-------|
| 📁 **قراءة وكتابة الملفات** | يقرأ ويعدّل أي ملف في المستودع مباشرة |
| ✍️ **بناء ميزات** | يفهم الطلب، يخطط، ينفّذ، يرفع على GitHub |
| ❓ **يسأل قبل يبني** | يطلب التوضيح عندما يحتاجه |
| ▶️ **تشغيل الكود** | يختبر الكود عبر Piston API (20+ لغة) |
| 🔍 **بحث** | يبحث في الإنترنت عبر DuckDuckGo |
| ♻️ **يعدّل نفسه** | يستطيع تعديل `src/bot.js` ← Railway يعيد النشر تلقائياً |
| 💬 **ذاكرة المحادثة** | يتذكر آخر 40 رسالة |

---

## المتغيرات البيئية (Railway)

| المتغير | الوصف | مطلوب |
|---------|-------|--------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather | ✅ |
| `TELEGRAM_OWNER_ID` | ايدي مالك البوت (رقمي) | ✅ |
| `OPENROUTER_API_KEY` | مفتاح OpenRouter API | ✅ |
| `GITHUB_PERSONAL_ACCESS_TOKEN` | توكن GitHub | ✅ |
| `GITHUB_OWNER` | اسم المستخدم على GitHub | ✅ |
| `GITHUB_REPO` | اسم المستودع | ✅ |
| `GITHUB_BRANCH` | الفرع (افتراضي: main) | اختياري |
| `AI_MODEL` | النموذج (افتراضي: anthropic/claude-3.5-sonnet) | اختياري |
| `MAX_HISTORY` | الرسائل المحفوظة (افتراضي: 40) | اختياري |

## النشر على Railway

1. اربط هذا المستودع بمشروع Railway
2. أضف المتغيرات البيئية المطلوبة
3. Railway سيشغّل `node index.js` تلقائياً

عند كل commit، Railway يعيد النشر — بما في ذلك إذا عدّل البوت نفسه! 🔄

- **DuckDuckGo** — البحث في الإنترنت
