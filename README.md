# 🤖 بوت تعديل GitHub عبر تيليجرام

بوت تيليجرام ذكي يتيح لك تعديل كود بوتك الآخر على GitHub بالعربي الفصيح.

---

## المتغيرات المطلوبة على Railway

| المتغير | الوصف |
|--------|-------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_OWNER_ID` | رقمك الشخصي على تيليجرام (من @userinfobot) |
| `GITHUB_PERSONAL_ACCESS_TOKEN` | توكن GitHub (صلاحية repo) |
| `GITHUB_OWNER` | `hseon19990-jpg` |
| `GITHUB_REPO` | `Assist` |
| `GITHUB_BRANCH` | `main` |
| `OPENAI_API_KEY` | مفتاح OpenAI لميزة التعديل بالعربي |

---

## الأوامر

### 🤖 تعديل بالعربي (GPT-4)
```
/ai
ملف: src/index.js
غير رسالة /start لتقول: أهلاً وسهلاً! أنا بوتك الذكي
```

### 📁 رفع ملف مباشر
أرسل أي ملف وسيسألك عن مساره في الريبو.

### ✏️ رفع محتوى نصي
```
/push
path: src/file.js
message: وصف التعديل
---
محتوى الملف هنا
```

### أوامر أخرى
- `/status` — عرض الإعدادات
- `/branch <اسم>` — تغيير الفرع
- `/cancel` — إلغاء العملية الحالية

---

## كيف تشتغل ميزة التعديل بالعربي؟

1. تكتب `/ai` مع اسم الملف وتعليماتك بالعربي
2. البوت يجلب الملف من GitHub
3. يرسله لـ GPT-4 مع تعليماتك
4. GPT-4 يعدّل الكود
5. البوت يرفع الملف المعدّل تلقائياً ويعرض معاينة

---

أي شخص يفتح البوت غيرك يحصل على رسالة رفض تلقائية.
